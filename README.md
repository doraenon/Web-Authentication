# Web认证 / Web-Authentication
这是一个由纯html构成的web认证系统的前端界面，它只能给你提供一个漂亮的界面，但需要你自己写javascript等验证逻辑。

This is the front-end interface for a web authentication system built entirely with HTML; it provides only a visually appealing interface, so you will need to write the validation logic—such as JavaScript—yourself.

# 运行环境 / Operate environment
任何具备html服务器的环境，或者本地直接双击鼠标打开它。

Any environment with a Web server, or simply double-click to open it locally.
